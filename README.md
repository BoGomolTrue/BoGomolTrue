### 💡 What I do

I design and ship **production backend systems** — from API layers and business logic to integrations, databases, and deployment.

- **Publishing & CMS** — backend for editorial platforms where teams create, schedule, and push content to **Telegram channels**, **YouTube Shorts**, and other social surfaces
- **Telegram integrations** — deep work with **Telegram API**: **MTProto** clients, **Bot API**, **TDLib**, channel & chat automation, media uploads, post scheduling, and account-level workflows
- **Editor workflows** — drafting, scheduling, publishing, media handling, and content pipelines
- **APIs & integrations** — REST services, third-party platform connectors, webhooks, background jobs
- **Data layer** — PostgreSQL / MongoDB / MySQL, Redis caching, reliable storage for high-volume content
- **Production infrastructure** — Docker, Linux, CI/CD, services built to run in real-world load
